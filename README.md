Nama Project : AdventureCamp
Deksripsi Project : Adventure Camp adalah program penyewaan peralatan camping berbasis bahasa C. Program ini menyediakan fitur daftar peralatan, penyewaan, perhitungan biaya dan diskon otomatis, struk pembayaran, serta riwayat transaksi. Program menggunakan array, fungsi, percabangan, perulangan, dan validasi input untuk mempermudah pengelolaan penyewaan peralatan camping.
